How it works
Connect two models, review the difference, ship only what you picked
Model Alchemist reads TMDL, not a black box. Every step below is inspectable before anything is written.
1

Connect

Source and Target are chosen independently. Any combination of local and Fabric.
SOURCE📁 local .SemanticModel folder
or ☁️ Fabric semantic model
TARGET📁 local .SemanticModel folder
or ☁️ Fabric semantic model
AUTHOAuth2 + PKCE in your browser.
No credentials stored on disk.
→
2

Compare

TMDL is parsed into identity-keyed objects and diffed property by property.
OBJECT-LEVEL DIFF
+measure Sales.Margin %
~column Sales.Amount
~partition Sales
−role Legacy Viewer
ATOMIC GROUPS Changes that must ship together are bound into one unit: a Power Query change with its dependent columns, a relationship with its endpoints, a rename with both sides.
→
3

Deploy

Tick what ships. Everything else in Target is left exactly as it was.
BEFORE ANYTHING IS WRITTEN
✓ dependency validation
✓ full-folder backup
✓ preview of every file operation
THEN Local: transactional write, rolled back on any failure.
Fabric: updateDefinition upload, then an Enhanced Refresh scoped to the tables that actually need it.
